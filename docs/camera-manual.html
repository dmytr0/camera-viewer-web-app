04 Живлення 12V DC

Модуль живиться від 12V DC через роз'єм у складі комбінованого кабелю (Ethernet + живлення). Роз'єм живлення на кабелі — 2.1×5.5 мм.

⚠️
Полярність кабелю не підписана! Перевірте мультиметром перед підключенням.
Центральний контакт = «+» (плюс) · Зовнішній контакт = «−» (мінус)
Роз'єм 2.1×5.5 мм ┌─────────┐ │ ● +12V │ ← центральний контакт (плюс) │ │ └── ○ GND ──┘ ← зовнішній контакт (мінус)

Розпіновка у кабелі

Колір дротуСигналОпис
Червоний+12VПін 1 основного роз'єму
ЧорнийGNDПін 2 основного роз'єму
ℹ️ Споживання: ~2–3 Вт у режимі очікування, до ~5 Вт при активному зумі. Використовуйте блок живлення ≥ 1А.

05 Ethernet підключення

Ethernet-сигнали виходять через 4-пінний роз'єм на основній платі і об'єднані в комбінований кабель разом із живленням 12V.

Основна плата Кабель Роз'єм RJ45 ┌──────────┐ ┌──────────┐ │ ETHRX− ──┼─────────────────────────┼── пара RX │ │ ETHRX+ ──┼─────────────────────────┼── пара RX │ │ ETHTX− ──┼─────────────────────────┼── пара TX │ │ ETHTX+ ──┼─────────────────────────┼── пара TX │ └──────────┘ └──────────┘

Стандартний 100 Мбіт Ethernet. Підключається до маршрутизатора або комутатора кабелем зі стандартним RJ45. DHCP увімкнено за замовчуванням.

06 ІЧ-фільтр (IRCUT)

IRCUT (Infrared Cut filter) — механічний фільтр, що перемикає камеру між денним та нічним режимом. Керується двома контактами безпосередньо з плати.

Роз'єм IRCUT видно праворуч на платі керування (позначено «Ircut interfaces»)

Підключення зовнішньої ІЧ-підсвітки

Зовнішня ІЧ-підсвітка підключається до контактів IRCUT+ / IRCUT− і керується автоматично прошивкою камери залежно від освітленості.

КонтактПідключення
IRCUT+«+» обмотки реле або «+» ІЧ-підсвітки (через реле)
IRCUT−«−» обмотки реле або «−» ІЧ-підсвітки
ℹ️
IRCUT-вихід видає невеликий струм (логічний рівень). Для керування потужною ІЧ-підсвіткою використовуйте проміжне реле або MOSFET-ключ.

Логіка роботи

День : IRCUT+ = HIGH → фільтр вставлено → кольорове зображення Ніч : IRCUT+ = LOW → фільтр прибрано → чорно-біле, ІЧ-підсвітка ON Авто : керується датчиком освітленості прошивки камери

07 PTZ керування (UART)

Модуль оснащений двома UART-каналами для керування PTZ-механізмом (Pan–Tilt–Zoom). UART виводиться на піни 3–6 основного 6-пінного роз'єму.

Розпіновка UART

ПінНазваПідключення до PTZ-привода
3RXD (UART1)→ TXD PTZ-привода
4TXD (UART1)→ RXD PTZ-привода
5RXD (UART2)→ TXD другого PTZ-пристрою
6TXD (UART2)→ RXD другого PTZ-пристрою
⚠️ UART-рівні 3.3V TTL. При підключенні до RS-485 PTZ-привода використовуйте конвертер TTL→RS-485.

Схема підключення PTZ-привода

Камера (6-пін) PTZ-привод ┌──────────┐ ┌──────────┐ │ Пін 3 RXD┼─────────────┼ TXD │ │ Пін 4 TXD┼─────────────┼ RXD │ │ Пін 2 GND┼─────────────┼ GND │ └──────────┘ └──────────┘ Для RS-485 PTZ: Камера UART → TTL-RS485 конвертер → A/B PTZ-привода

Керування зумом об'єктиву

30x оптичний зум керується безпосередньо через мережевий інтерфейс (HTTP/Onvif). Команди Zoom In / Zoom Out надсилаються з веб-інтерфейсу або Onvif-клієнта — окремого фізичного підключення для зуму не потрібно.

08 WiFi модуль

WiFi-модуль підключається до 4-пінного роз'єму на платі керування через інтерфейс USB. У комплекті варіанта «Add WiFi» модуль вже встановлений.

Роз'єм WiFi-модуля

┌───┬───────┬────────────────────────────┐ │ 1 │ 3.3V │ Живлення модуля │ │ 2 │ USB− │ USB Data Minus │ │ 3 │ USB+ │ USB Data Plus │ │ 4 │ GND │ Земля │ └───┴───────┴────────────────────────────┘

Режим WiFi

  • Підтримує режим AP (точка доступу) — камера сама створює WiFi-мережу
  • Підтримує режим Client (клієнт) — камера підключається до існуючого роутера
  • Налаштування SSID та пароля — через веб-інтерфейс або Onvif
ℹ️ При першому підключенні рекомендується налаштовувати камеру через Ethernet, а потім переключатися на WiFi.

09 TF-карта (microSD)

Слот для TF/microSD карти винесений на окрему маленьку плату і підключається до основної через FPC-кабель (гнучкий шлейф).

TF-card плата підключається до основної через FPC-шлейф
  • Підключення: FPC-кабель між основною платою та платою TF-слоту
  • Підтримуваний формат карток: microSD / TF
  • Використовується для локального запису відео
  • Вставляти картку при вимкненому живленні камери
⚠️ FPC-кабель крихкий. Не перегинайте та не натягуйте. При монтажі залишайте достатній радіус вигину.

10 Мережа, веб-інтерфейс та RTSP

Перший запуск

  1. Підключіть Ethernet та живлення
    Ethernet через комбінований кабель до роутера, живлення 12V з правильною полярністю.
  2. Знайдіть IP-адресу камери
    Відкрийте список DHCP-клієнтів у роутері, або скористайтесь Onvif Device Manager (Windows, безкоштовно) — він автоматично виявляє камеру в локальній мережі.
  3. Відкрийте веб-інтерфейс
    У браузері введіть IP-адресу камери. Стандартні дані: логін admin, пароль — порожньо.

Веб-інтерфейс камери

# Адреса веб-інтерфейсу
http://<IP-камери>

# Логін за замовчуванням
User:     admin
Password: (порожнє)

Через веб-інтерфейс налаштовуються: роздільна здатність, бітрейт, виявлення руху/людини, IRCUT-режим, розклад запису, PTZ-пресети, WiFi.

RTSP-потік

# Основний потік (отримано через Onvif Device Manager)
rtsp://<IP-камери>/11

# Приклад:
rtsp://192.168.1.100/11

# Для VLC: Медіа → Відкрити мережевий потік → вставте URL
ℹ️ Точну RTSP-адресу рекомендується отримати через Onvif Device Manager → Media → Profiles → Stream URI, оскільки вона може відрізнятися залежно від версії прошивки.

Onvif

  • Стандартний порт Onvif: 80 або 8080
  • Підтримує: перегляд потоку, PTZ-команди (Zoom In/Out, Pan, Tilt), пресети, налаштування зображення
  • Сумісний з: Onvif Device Manager, Blue Iris, iSpy, Home Assistant, Frigate
